# Технический отчёт: Job Finder Agent

**Автор:** Онищенко Павел Владимирович  
**Проект:** Агент для автоматизированного поиска вакансий  
**Дата:** октябрь 2026

---

## 1. Постановка задачи

Разработать агент, который автоматически:

1. Собирает вакансии с hh.ru по заданным критериям (аналитик данных, удалёнка).
2. Фильтрует их по релевантности.
3. Сохраняет результаты в PostgreSQL.
4. Выводит ТОП-10 наиболее подходящих вакансий с прямыми ссылками.

**Проблема:** в апреле 2026 года hh.ru **закрыл публичный API** для поиска вакансий (`GET /vacancies`). Любой запрос без токена приложения возвращает `403 Forbidden`. Поэтому классический подход через `api.hh.ru` перестал работать.

## 2. Решение: парсинг HTML-страниц

Вместо закрытого API агент использует **парсинг публичной HTML-страницы** поиска вакансий.

### Как это работает

1. Агент делает GET-запрос к `https://hh.ru/search/vacancy?text=...` с **браузерным User-Agent**.
2. hh.ru возвращает HTML-страницу со статусом 200.
3. Внутри HTML в теге `<template id="HH-Lux-InitialState">` лежит JSON с данными вакансий.
4. Агент извлекает JSON через `BeautifulSoup` и `json.loads()`.
5. Данные нормализуются в формат, похожий на API-ответ (для совместимости).

### Преимущества подхода

- ✅ Работает **без токена** и регистрации.
- ✅ Возвращает **50 вакансий на страницу** (100+ за 2 страницы).
- ✅ Легально: это чтение публично доступной страницы, а не взлом.

### Ограничения

- ⚠️ Формат HTML может измениться — код потребует обновления.
- ⚠️ В HTML **не передаётся поле `snippet.requirement`** (описание требований). Поэтому скоринг работает только по названию вакансии.
- ⚠️ Ограничение на количество страниц (обычно 40 по 50 вакансий).

## 3. Архитектура

### Компоненты

| Модуль | Назначение |
|--------|-----------|
| `fetch_vacancies()` | Сбор вакансий через парсинг HTML |
| `save_vacancies()` | Сохранение в PostgreSQL с дедупликацией |
| `filter_vacancies()` | Скоринг и фильтрация по релевантности |
| `show_top_vacancies()` | Вывод ТОП-10 в консоль |

### Схема БД

**Таблица `vacancies`** — сырые данные:

- `hh_id` (UNIQUE) — ID вакансии на hh.ru
- `name`, `employer_name`, `salary_from`, `salary_to`
- `description`, `url`, `published_at`

**Таблица `filtered_vacancies`** — отфильтрованные:

- `vacancy_id` (FK → vacancies.id)
- `relevance_score` — балл релевантности
- `match_reason` — какие ключевые слова совпали

### Разделение прав БД

- **`postgres`** — владелец схемы и таблиц (администратор).
- **`course`** — пользователь приложения (только чтение/запись данных).

Команда `ALTER SCHEMA pavel_onichtchenko OWNER TO course` передаёт владение схемой пользователю приложения.

## 4. Алгоритм скоринга

Каждой вакансии присваивается **relevance_score** — сумма весов найденных ключевых слов.

| Ключевое слово | Вес |
|----------------|-----|
| sql, python | 5 |
| pandas, postgresql, power bi | 4 |
| аналитик | 4 |
| данных, bi, дашборд, data, analyst | 3 |
| tableau, excel | 3 |
| product, бизнес, отчет | 2 |

**Порог:** вакансия попадает в `filtered_vacancies`, если `score >= 5`.

### Примеры

| Название вакансии | Совпало | Score |
|-------------------|---------|-------|
| Дата-аналитик (SQL, Python) | sql, python, аналитик, данных | 17 |
| Аналитик данных / Data Analyst | аналитик, данных, data, analyst | 13 |
| BI-аналитик | bi, аналитик | 7 |
| Продуктовый аналитик | product, аналитик | 6 |

## 5. Результаты

После запуска агента:

- **100 вакансий** загружено с 2 страниц hh.ru.
- **185 вакансий** проверено (100 новых + 85 из прошлых запусков).
- **57 вакансий** отфильтровано как релевантные.
- **ТОП-10 выведен** в консоль с полной информацией.

### Пример топ-3

1. **Дата-аналитик (SQL, Python)** — Честный знак.рф — score 14
2. **Аналитик данных / Data Analyst (Senior)** — Займиго МКК — score 13
3. **Аналитик данных / Data Analyst** — ТАРГЕТ АДС — 110 000-200 000 ₽ — score 13

## 6. Ограничения и направления развития

### Текущие ограничения

- Поле `description` не заполняется (нет в HTML-версии).
- Скоринг работает только по названию вакансии.
- Нет автоматической отправки откликов (запрещено правилами hh.ru).
